# 無人島サバイバル Mod 進捗設計

## Chapter 1: 漂着

### 進捗: 目を覚ませ
**条件:** ワールドに初めてスポーンする  
**説明:** 海に囲まれた孤島でサバイバルを始める

### 進捗: まずは足元から
**条件:** 小石を拾う  
**説明:** 道具作りに使える小石を集める

### 進捗: 手では無理だ
**条件:** 素手で原木を壊そうとする  
**説明:** この世界では、素手で木を倒すことはできない

### 進捗: 最初の刃
**条件:** 枝、小石、糸で石ナイフをクラフトする  
**説明:** 生存の第一歩となる簡易ナイフを作る
